KHATA - .exe aur .apk banane ke steps
1. github.com par free account banayein.
2. New repository banayein (naam: khata, Public ya Private dono chalega).
3. "uploading an existing file" par click karke is zip ko extract karke andar ki SARI files/folders drag-drop karein, phir Commit changes dabayein.
   Agar .github folder upload nahi hua: Add file > Create new file, naam likhein  .github/workflows/build.yml  aur uska content paste karein.
4. Upar "Actions" tab kholein, "Build exe and apk" chunein, Run workflow dabayein. 5-10 minute lagte hain.
5. Run poora hone par neeche "Artifacts" mein Khata-Windows-exe aur Khata-Android-apk download karein (zip hoga, extract karein).
6. PC: .exe double-click karein. Mobile: .apk phone mein bhejein, "Unknown sources se install" allow karke install karein.
